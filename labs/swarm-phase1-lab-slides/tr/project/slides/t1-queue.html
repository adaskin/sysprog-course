queue_t *queue_create(size_t cap, size_t item_size);

int queue_push(queue_t *q, const void *item); // doluysa bekler

int queue_try_push(queue_t *q, const void *item); // doluysa -1

int queue_pop(queue_t *q, void *out); // boşsa bekler

void queue_close(queue_t *q); // herkesi uyandırır

size_t queue_size(queue_t *q); void queue_destroy(queue_t *q);

İki yerde kullanılır: center’ın istek kuyruğu (try_push, doluysa BUSY) ve leader’ın tema kuyruğu.

Kurallar

  • Her pthread_cond_wait’in etrafında if değil while
  • close’dan sonra: pop kalanları boşaltır, sonra −1 döner; push −1 döner
  • close herkesi uyandırır: broadcast
  • Meşgul bekleme (busy-waiting) yok, sleep yok

BIL 322 · Swarm Faz 1 laboratuvarı

Görev 1, derste gördüğün klasik sınırlı tampon (bounded buffer): bir mutex ve condition variable'larla halka tampon. İki condition variable (dolu değil, boş değil) mantığı okunur kılar. Öğeler değerle kopyalanır; bu yüzden aynı kuyruk int'leri, istekleri ve temaları taşıyabilir. while kullan: sahte uyanmalar (spurious wakeup) var ve başka bir thread öğeyi senden önce alabilir. queue_close'dan sonra pop kalan öğeleri döndürmeye devam eder, sonra başarısız olur; böylece worker'lar kuyruğu boşaltıp çıkar. push ise hemen başarısız olur; push'ta zaten bloke olmuş bir thread için de. close herkesi uyandırmalı: signal değil broadcast. Meşgul bekleme ve sleep yok. Projenin geri kalanı yokken kuyruğu tests/test_queue ile tek başına test edebilirsin.
