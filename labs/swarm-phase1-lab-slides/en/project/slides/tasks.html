BIL 322 · Swarm Phase 1 lab

This is the whole assignment on one page. The skeleton repository already contains the protocol parser, the planner (the slow stand-in for an LLM), the plan validator, the score and image loaders, the center’s clock loop and the tests. You fill in the TODO blocks. Task 1: the bounded queue. Task 2: the request pipeline in the center and the thinker in the leader. Task 3: the occupancy grid in both lock modes and the follower threads. Task 4: a deadlock that is already in grid_swap; you reproduce it, explain it and fix it. Task 5: notice a dead captain and restart it. Task 6: make test and make tsan must pass, plus a short report. The handout has the details of each task.
