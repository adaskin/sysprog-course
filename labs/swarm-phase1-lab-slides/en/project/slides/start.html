Getting started

Build, test, and the order to work in

cd labs/swarm-phase1-skeleton

make # builds, TODOs are empty

make test # PASS/FAIL per check

make tsan # no WARNING allowed

make bench # one lock vs row locks

./center --tempo 0 --ascii 8

The full show needs Tasks 1 to 3 together. Until then test each piece alone: test_queue, swapstress, gridbench, or type protocol lines into ./leader --id 0.

Suggested order

  1. queue.c
  2. grid claim, release, owner
  3. center: serve_request
  4. leader: thinker
  5. leader: followers
  6. captain restart
  7. the deadlock fix

BIL 322 · Swarm Phase 1 lab

Everything is in the skeleton repository; its README.md explains the layout. make builds center, leader and the tools, and make test runs a script that prints PASS or FAIL for each check. At the start nearly everything fails: that is expected. The whole show only runs when the queue, the planner pipeline and the followers all exist, so work in the suggested order and test the pieces separately: the queue has its own unit test, the grid has swapstress and gridbench, and you can type protocol lines into a leader by hand. If your Lab 6 kvpool.c and arena.c work, copy them into src/ and the Makefile uses them instead of the stand-in.
