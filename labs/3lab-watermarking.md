## 2. Background: BMP File Structure

A BMP file has a well-defined binary layout:

```text
┌──────────────────────────────────┐
│  BMP File Header (14 bytes)      │  ← file type, size, offset to pixel data
├──────────────────────────────────┤
│  DIB Header (variable size)      │  ← width, height, bits per pixel, etc.
├──────────────────────────────────┤
│  Color Table (optional)          │  ← for low bit-depth images
├──────────────────────────────────┤
│  Pixel Data                      │  ← raw pixel values (BGRX for 32-bit)
└──────────────────────────────────┘
```

Key offsets:

| Offset | Field | Size |
|---|---|---|
| 0 | File type (`"BM"`) | 2 bytes |
| 10 | Pixel data offset | 4 bytes |
| 14 | DIB header size | 4 bytes |
| 18 | Image width | 4 bytes |
| 22 | Image height | 4 bytes |
| 26 | Color planes | 2 bytes |
| 28 | Bits per pixel | 2 bytes |
| 30 | Compression method | 4 bytes |

For this lab, we use **uncompressed 32-bit BMP files** (4 bytes per pixel: B, G, R, X/A). The provided `read_image` validates this and refuses to load other variants.

---

## 3. Background: Little-Endian Byte Order

Multi-byte integers in BMP files are stored in **little-endian** order (least significant byte first).

Example: the 32-bit value `0x12345678` is stored in memory as:

```text
Address:  [0]   [1]   [2]   [3]
Bytes:    0x78  0x56  0x34  0x12
```

This is why we use a **union** to access pixel data both as a single `uint32_t` and as individual bytes.

---

## 4. Background: LSB Watermarking

The least significant bit (LSB) of a color channel contributes minimally to the perceived color. Modifying it changes the color value by at most 1 out of 255.

Example:

```text
Original pixel:    R=128, G=64, B=200
After embedding:   R=129, G=64, B=201  ← only LSB changed
```

The human eye cannot detect this difference, but software can extract the hidden bits.

### Capacity

For a 32-bit BMP image of size `W × H`:

- Each pixel has 3 usable channels (B, G, R — we skip the alpha/X byte).
- Each channel stores `n` bits of the watermark.
- Total capacity = `W × H × 3 × n` bits = `W × H × 3 × n / 8` bytes.

Example: a 100×100 image with 1 bit per channel can store:

```text
100 × 100 × 3 × 1 / 8 = 3750 bytes ≈ 3.7 KB
```

### Bit stream convention (important for Task 4)

Throughout this lab we treat the message as one continuous bitstream, not as per-character groups:

1. Concatenate the 8 bits of every message byte (MSB first), including the terminating `'\0'`.
2. Walk through channels in the order B, G, R, B, G, R, … (skip A).
3. For each channel, take the next `n` bits from the stream and write them into the low `n` bits of that channel.
4. If the last chunk is short, pad it with zeros on the right — the decoder will stop on the `'\0'` byte before it reads any padding.

This convention matches the capacity formula above. (If instead you padded each character separately, `n = 3` would need `ceil(8/3) × 3 = 9` bits per character, and the capacity check would be wrong.)

### 5.4 Task 2: Encode a watermark (`encode_message`)

Implement:

```c
int encode_message(Image *img, const char *message, uint8_t nbit_per_channel);
```

Behavior:

1. Reject invalid inputs:
   - `img == NULL`
   - `message == NULL`
   - `nbit_per_channel < 1`
   - `nbit_per_channel > 8`

2. Compute the total number of bits needed:

   ```c
   total_bits = (strlen(message) + 1) * 8
   ```

   The `+1` includes the null terminator.

3. Compute the number of channels needed:

   ```c
   channels_needed = ceil(total_bits / nbit_per_channel)
   ```

4. Compute the number of pixels needed:

   ```c
   pixels_needed = ceil(channels_needed / 3)
   ```

5. If `pixels_needed > width * height`, print an error and return `-1`.

6. Otherwise, walk over the channels in the order B, G, R (per pixel), and for each channel write the next `n` bits of the message bitstream using `set_nlsb()`.

7. Return `0` on success.

Note: the 1-bit case is just `n = 1`. Get that working first, then generalize.

### 5.5 Task 3: Decode a watermark (`decode_message`)

Implement:

```c
char *decode_message(const Image *img, uint8_t nbit_per_channel);
```

Behavior:

1. Reject invalid inputs:
   - `img == NULL`
   - `nbit_per_channel < 1`
   - `nbit_per_channel > 8`

   Return `NULL` on invalid input.

2. Allocate a buffer large enough for `total_bits / 8` characters plus a null terminator.

3. Walk over the channels in the order B, G, R (per pixel) and read the low `n` bits of each channel with `get_nlsb()`.

4. Accumulate the bits into a byte buffer, emitting one character every 8 bits.

5. Stop as soon as the emitted character is `'\0'`. Null-terminate the buffer and return it.

6. If allocation fails, print an error and return `NULL`. The caller must `free()` the returned string.

### `image.h`

```c
#ifndef IMAGE_H
#define IMAGE_H

#include <stdint.h>
#include <stdio.h>

/** Pixel structure: access as uint32_t or individual channels */
typedef union {
    uint32_t value; /* Raw 32-bit pixel value (BGRX) */
    struct {
        uint8_t b; /* Blue */
        uint8_t g; /* Green */
        uint8_t r; /* Red */
        uint8_t a; /* Alpha/X (unused in 32-bit BMP) */
    } __attribute__((packed));
} Pixel;

typedef struct {
    void *header;      /* Header data (bytes 0 to offset) */
    uint32_t offset;   /* Byte offset where pixel data starts */
    uint32_t width;    /* Image width in pixels */
    uint32_t height;   /* Image height in pixels */
    Pixel *pixels;     /* Array of pixels (size = width * height) */
} Image;

/* Returns the offset on success, or -1 on failure. */
int read_header(FILE *file, Image *img);

/* Returns a fully-loaded Image on success, or NULL on failure. */
Image *read_image(FILE *file);

Image *load_image(const char *filename);

/* Safe to call on partially constructed images and on NULL. */
void free_image(Image *img);

/* Returns 0 on success, -1 on failure. */
int save_image(const Image *img, const char *filename);

#endif
```

### `image.c`

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

#include "image.h"

int read_header(FILE *file, Image *img) {
    if (fseek(file, 10, SEEK_SET) != 0) {
        perror("read_header: fseek failed");
        return -1;
    }

    if (fread(&img->offset, sizeof(img->offset), 1, file) != 1) {
        fprintf(stderr, "read_header: failed to read pixel offset\n");
        return -1;
    }

    img->header = malloc(img->offset);
    if (!img->header) {
        perror("read_header: header allocation failed");
        return -1;
    }

    if (fseek(file, 0, SEEK_SET) != 0) {
        perror("read_header: fseek to start failed");
        return -1;
    }

    size_t n = fread(img->header, 1, img->offset, file);
    if (n != img->offset) {
        fprintf(stderr,
                "read_header: expected %u header bytes, got %zu\n",
                img->offset, n);
        return -1;
    }

    return (int)img->offset;
}

Image *read_image(FILE *file) {
    Image *img = malloc(sizeof(Image));
    if (!img) {
        perror("read_image: Image allocation failed");
        return NULL;
    }

    /* Initialize fields so free_image is safe on any failure path. */
    img->header = NULL;
    img->pixels = NULL;
    img->offset = 0;
    img->width  = 0;
    img->height = 0;

    if (read_header(file, img) < 0) {
        free_image(img);
        return NULL;
    }

    uint32_t width = 0, height = 0, compression = 0;
    uint16_t planes = 0, nbits = 0;

    if (fseek(file, 18, SEEK_SET) != 0) {
        perror("read_image: fseek failed");
        free_image(img);
        return NULL;
    }

    if (fread(&width,       sizeof(width),       1, file) != 1 ||
        fread(&height,      sizeof(height),      1, file) != 1 ||
        fread(&planes,      sizeof(planes),      1, file) != 1 ||
        fread(&nbits,       sizeof(nbits),       1, file) != 1 ||
        fread(&compression, sizeof(compression), 1, file) != 1) {
        fprintf(stderr, "read_image: failed to read BMP header fields\n");
        free_image(img);
        return NULL;
    }

    if (planes != 1 || nbits != 32 || compression != 0) {
        fprintf(stderr,
                "read_image: only uncompressed 32-bit BMP is supported "
                "(got planes=%u, bpp=%u, compression=%u)\n",
                planes, nbits, compression);
        free_image(img);
        return NULL;
    }

    if (width == 0 || height == 0) {
        fprintf(stderr, "read_image: invalid image dimensions\n");
        free_image(img);
        return NULL;
    }

    img->width  = width;
    img->height = height;

    img->pixels = malloc((size_t)width * height * sizeof(Pixel));
    if (!img->pixels) {
        perror("read_image: pixel array allocation failed");
        free_image(img);
        return NULL;
    }

    if (fseek(file, img->offset, SEEK_SET) != 0) {
        perror("read_image: fseek to pixel data failed");
        free_image(img);
        return NULL;
    }

    size_t expected = (size_t)width * height;
    size_t n = fread(img->pixels, sizeof(Pixel), expected, file);
    if (n != expected) {
        fprintf(stderr, "read_image: expected %zu pixels, got %zu\n",
                expected, n);
        free_image(img);
        return NULL;
    }

    return img;
}

Image *load_image(const char *filename) {
    if (!filename) {
        fprintf(stderr, "load_image: filename is NULL\n");
        return NULL;
    }

    FILE *file = fopen(filename, "rb");
    if (!file) {
        perror("load_image: fopen failed");
        return NULL;
    }

    Image *img = read_image(file);
    fclose(file);
    return img;
}

int save_image(const Image *img, const char *filename) {
    if (!img || !filename) {
        fprintf(stderr, "save_image: invalid argument\n");
        return -1;
    }

    FILE *file = fopen(filename, "wb");
    if (!file) {
        perror("save_image: fopen failed");
        return -1;
    }

    if (fwrite(img->header, 1, img->offset, file) != img->offset) {
        perror("save_image: failed to write header");
        fclose(file);
        return -1;
    }

    size_t expected = (size_t)img->width * img->height;
    if (fwrite(img->pixels, sizeof(Pixel), expected, file) != expected) {
        perror("save_image: failed to write pixels");
        fclose(file);
        return -1;
    }

    if (fclose(file) != 0) {
        perror("save_image: fclose failed");
        return -1;
    }

    return 0;
}

void free_image(Image *img) {
    if (img == NULL) {
        return;
    }

    free(img->header);
    free(img->pixels);
    free(img);
}
```

### `lsbstegan.c`

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include "image.h"
#include "lsbstegan.h"

/* Set the LSB of a byte to a bit value (0 or 1) */
uint8_t set_lsb(uint8_t byte, uint8_t bit) {
    return (uint8_t)((byte & 0xFE) | (bit & 1));
}

/* Get the LSB of a byte */
uint8_t get_lsb(uint8_t byte) {
    return (uint8_t)(byte & 1);
}

/*
 * TODO: Set the lowest n bits of dest to the lowest n bits of src.
 *
 * Example: set_nlsb(0xAB, 0x05, 3)
 *   0xAB = 10101011
 *   Keep top 5 bits: 10101___
 *   Lowest 3 bits of 0x05 = 101
 *   Result: 10101101 = 0xAD
 *
 * Hints:
 *   - Mask for the top (8 - n) bits of dest:  ~((1u << n) - 1u)
 *   - Mask for the low n bits of src:          (1u << n) - 1u
```
